# World Projection 3×3 v0.2.0 — validation and sharing status

## What this bundle is

A reviewed Python 3 synthetic simulator package and its reproducible run record. It is **not** the newer interactive Muse game: no new browser-game frontend or new Muse share URL was present in the available source. The Muse link retained in the package README is the earlier v0.1.0 game and must not be presented as this build.
